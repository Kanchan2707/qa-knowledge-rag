# Bug Severity and Reporting

## Severity levels
P1 means an outage or data loss, and it must be fixed within 4 hours. P2 means a major feature is broken with no workaround, and it must be fixed within 2 business days. P3 is a minor problem and is scheduled for the next sprint. P4 is cosmetic and goes to the backlog.

## What a bug report must contain
Every bug report needs the steps to reproduce, the expected result, the actual result and the build number where it was found. Screenshots or logs should be attached when they help. Reports missing these fields are returned to the reporter.
